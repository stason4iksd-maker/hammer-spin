# HL2 Hammer Oracle

**HL2 Hammer Oracle** — интерактивный генератор идей и заданий для мапперов Half-Life 2, выполненный в стилистике футуристического терминала Альянса.

## Особенности

- 20 уникальных проектов для создания карт в Half-Life 2
- Колесо случайного выбора с плавной анимацией вращения
- Три уровня сложности для каждого задания:
  - Лёгкий
  - Средний
  - Сложный
- Интерфейс в стиле технологий Альянса
- Визуальные эффекты:
  - Голографические карточки
  - Частицы и вспышки
  - Анимированный фон
  - HUD-элементы и скан-линии
- Звуковые эффекты через Web Audio API
- История последних полученных заданий
- Кастомный курсор и интерактивные эффекты наведения
- Адаптивный дизайн без сторонних фреймворков

## Как это работает

1. Нажмите «Получить задание».
2. Колесо выберет случайный проект.
3. Откройте секретную карточку.
4. Получите описание задания и варианты реализации разной сложности.
5. Создайте карту в Hammer Editor по выпавшей идее.

## Примеры проектов

- Камера наблюдения Альянса
- Бункер выживших
- Телепорт Альянса

- SVG

## Цель проекта

Проект создан для вдохновения мапперов и помощи в поиске новых идей для карт. Генератор случайным образом выдаёт концепцию проекта и предлагает несколько вариантов её реализации разной сложности.
